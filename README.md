# ZeraForge Website

A fully responsive, futuristic, and high-performance website for ZeraForge - a startup that focuses on hiring, training, and teaming up B.Tech students to work on real client projects.

## Features

- Fully responsive design optimized for desktop, tablet, and mobile devices
- Modern, futuristic UI with navy blue dark background and flaming red accents
- Interactive animations using Anime.js and AOS (Animate On Scroll)
- Dynamic particle background with particles.js
- Smooth scrolling and navigation
- Interactive 3D card effects and parallax scrolling
- Animated counters and text typing effect
- Testimonial slider with automatic rotation

## Technologies Used

- HTML5
- CSS3 (with CSS variables and modern effects)
- JavaScript (ES6+)
- [Anime.js](https://animejs.com/) - For sophisticated animations
- [AOS](https://michalsnik.github.io/aos/) - For scroll-based animations
- [Particles.js](https://vincentgarreau.com/particles.js/) - For interactive particle backgrounds
- [Typed.js](https://github.com/mattboldt/typed.js/) - For text typing animation
- [Font Awesome](https://fontawesome.com/) - For icons

## Sections

1. **Home** - Hero section with animated text and particle background
2. **Expertise** - Showcasing the company's core competencies with animated flip cards
3. **Team** - Team members with flip card animations
4. **Events** - Upcoming events with timeline layout
5. **About Us** - Company information with animated stats counters
6. **Testimonials** - Client and student testimonials with slider
7. **Contact** - Contact form with animated form fields

## How to Use

1. Clone the repository
2. Open `index.html` in your browser
3. Alternatively, deploy to a web server

## Customization

- Colors can be modified in the CSS variables at the top of the `styles.css` file
- Content can be updated in the `index.html` file
- Animation settings can be adjusted in the `main.js` file

## Browser Support

The website is designed to work on all modern browsers including:
- Chrome
- Firefox
- Safari
- Edge
